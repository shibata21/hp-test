# HP Test — 運用検証用サイト（Google製品連携版）

ポートフォリオの「Natural」サンプルをベースに、
**Googleフォーム** + **Googleスプレッドシート** で運用するテストサイトです。
**完全無料・追加契約なし。** 売り切り納品に最適。

---

## セットアップ

### 1. お知らせ（Google スプレッドシート）

#### 1-1. スプレッドシートを作成
[sheets.google.com](https://sheets.google.com) で新規作成し、1行目を以下の通りに：

| 日付 | カテゴリ | タイトル | 本文 |
|------|---------|---------|------|
| 2025-04-25 | お知らせ | GW営業時間 | 4/29〜5/6は… |
| 2025-04-10 | 新商品 | 新作入荷 | 春の新作が… |

**カテゴリの推奨値**: `お知らせ` / `イベント` / `新商品` / `季節`
（自動で色分けされます。それ以外でも表示はできます）

#### 1-2. CSVで公開
1. メニュー: **ファイル → 共有 → ウェブに公開**
2. 「リンク」タブ → シートを選択 → 形式「**カンマ区切り形式 (.csv)**」
3. 「公開」ボタン → 表示されたURLをコピー
4. `config.js` の `NEWS_SHEET_CSV_URL` に貼り付け

> ⚠ 「ウェブに公開」は、シート全体を読み取り専用で公開する設定です。
> 編集は引き続きオーナーのみ可能。

---

### 2. お問い合わせ（Google フォーム）

#### 2-1. フォーム作成
[forms.google.com](https://forms.google.com) で新規作成し、以下の項目を追加：

| 質問 | 種類 | 必須 |
|------|------|------|
| お名前 | 記述式 | ✓ |
| メールアドレス | 記述式 | ✓ |
| 電話番号 | 記述式 | |
| お問い合わせ種別 | プルダウン or ラジオ | |
| お問い合わせ内容 | 段落 | ✓ |

#### 2-2. メール通知をON
1. 「回答」タブを開く
2. 右上の「︙」→ **新しい回答のメール通知を受け取る**

#### 2-3. POST用URL取得
1. プレビュー（目のアイコン）でフォームを開く
2. URL末尾の `/viewform` を `/formResponse` に変更してメモ
   - 例: `https://docs.google.com/forms/d/e/1FAIp.../formResponse`
3. `config.js` の `CONTACT_FORM.url` に貼り付け

#### 2-4. 各フィールドのentry IDを取得
1. プレビュー画面で各入力欄を**右クリック → 検証**（または F12 → 該当要素クリック）
2. `name="entry.XXXXXXXX"` の数字部分をメモ
3. `config.js` の `CONTACT_FORM.fields` に5つすべて貼り付け

例:
```js
fields: {
  name:     'entry.1234567890',
  email:    'entry.2345678901',
  tel:      'entry.3456789012',
  category: 'entry.4567890123',
  message:  'entry.5678901234'
}
```

---

## 運用イメージ（クライアント目線）

### お知らせを追加する
1. Googleスプレッドシートを開く
2. 一番下に新しい行を追加（日付・カテゴリ・タイトル・本文）
3. **保存不要 → 数秒〜数分でサイトに反映**

### 問い合わせメールを受け取る
1. 何もしなくてOK
2. ユーザーが送信すると Gmail に自動通知が届く
3. すべての回答は接続先のスプレッドシートでも閲覧可能

---

## 制限事項

- スプレッドシートCSVの反映は最大5分程度の遅延あり（Google側のキャッシュ）
- 大量アクセスでGoogle側のレート制限の可能性（小売店レベルでは問題なし）
- フォーム送信エラーはブラウザに通知できない（CORS制約のため、送信は成功する）
